# 7-Day Consumer-Driven Contract Testing with Pact & TypeScript

## Prerequisites
- Node.js 18+
- Docker Desktop
- npm

## Quick Start
```bash
git clone <repo-url>
cd contract-testing-roadmap
npm install
docker-compose up -d
```
